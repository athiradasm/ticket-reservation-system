# Problems Encountered and Solutions

> Use this as a problem-tracking template. The examples below are common risks for this type of project; retain only problems you actually encounter and write the real fix you applied.

| No. | Possible problem | Suggested investigation / solution | Actual observation and resolution |
|---|---|---|---|
| 1 | Difficulty setting up Git or connecting the repository | Check Git installation, remote URL, authentication, and branch name | Fill in during lab |
| 2 | Unclear user navigation | Draw the user journey and review each screen in the storyboard | Fill in during lab |
| 3 | Empty search results | Check search criteria, sample data, and filtering conditions | Fill in during lab |
| 4 | Invalid or missing form input | Add client- and server-side validation with clear messages | Fill in during lab |
| 5 | Duplicate or conflicting seat selection | Recheck availability at confirmation and prevent double booking in the data layer | Fill in during lab |

| 7 | Booking does not appear in history | Verify reservation is saved and associated with the signed-in user | Fill in during lab |
| 8 | Cancellation does not update availability/status | Define cancellation rules and update reservation and inventory consistently | Fill in during lab |
